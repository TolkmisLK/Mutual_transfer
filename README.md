# Mutual Transfer

在局域网内，从电脑、手机或平板发送文件，并在另一台设备下载。

**当前是开发预览。** 已实现可运行的单空间服务和响应式浏览器客户端；原生桌面/移动安装包、真实跨设备大文件验收仍在开发路线中，尚未正式发布。

Windows 免安装服务包正在构建验收中，包含固定版本 Node 运行时、双击启动入口和独立用户数据目录；它使用浏览器界面，不是原生桌面客户端。实际下载和验收边界见 [Windows portable 说明](docs/WINDOWS-PORTABLE.md)。

## 运行

安装 Node.js 22 或更新版本，下载源码，在目录中运行：

```sh
npm start
```

首次运行前先执行 `npm ci` 安装锁定依赖。打开 `http://127.0.0.1:8787`，输入终端显示的访问密钥。浏览器增量 SHA-256 使用锁定的 `@noble/hashes` 实现，不自行编写哈希算法。密钥不写入访问日志或浏览器持久存储；文件和断点保存在 `data/`。重启后默认生成新密钥，原文件保留。

### 连接其他设备

正式使用需为局域网主机配置受客户端信任的 TLS 证书，并设置 `HOST=0.0.0.0`、`TLS_CERT`、`TLS_KEY`。自定义域名同时设置 `ALLOWED_HOSTS`（逗号分隔的主机名，不包含端口）。在其他设备打开该主机的 HTTPS 地址。配置示例、证书信任与故障边界见 [HTTPS 部署说明](docs/HTTPS.md)。

已用访问密钥登录的设备可生成单次、5 分钟有效的临时配对码，让新设备加入 1 小时而不接触长期密钥。配对成员仍能上传、下载和删除空间内全部文件，但不能继续邀请新设备；撤销未用配对码不会踢出已加入成员。配对不代替证书信任，非回环 HTTP 不提供配对。详见 [配对与撤销边界](docs/PAIRING.md)。

仅在可信网络进行临时测试，可显式允许 HTTP：

```sh
# macOS / Linux
HOST=0.0.0.0 MUTUAL_ALLOW_HTTP=1 npm start
```

```powershell
# Windows PowerShell
$env:HOST='0.0.0.0'
$env:MUTUAL_ALLOW_HTTP='1'
npm start
```

其他设备访问 `http://电脑局域网IP:8787`。HTTP 不加密密钥和文件，不能用于公开网络或敏感文件。只允许应用所需的局域网入站端口，不必关闭整个防火墙。

## 已实现

- 任意文件格式按 4 MiB 分块上传，默认总容量上限 100 GiB、最多 1000 个文件。
- 进度、暂停、重新选择原文件续传；服务重启后恢复已保存断点。
- Range 下载与视频拖动；图片、浏览器支持的视频和前 64 KiB 文本预览。
- 发送前分块计算源文件 SHA-256；上传时逐块校验，接收完成后再次核对全文件哈希。
- 访问密钥换取一小时 HttpOnly 会话；来源/主机校验、并发上限和路径校验。

一个密钥对应一个共享空间：所有成员都可以读取和删除其中的文件。不是多租户系统。文件先存入运行服务的电脑，再由其他设备下载；这一版不是设备直连协议。

续传时重新选择原文件，客户端会重新计算内容哈希；同名、同大小但内容不同的文件不会复用旧断点。哈希计算和上传均按 4 MiB 读取，不会把整个大文件载入内存。客户端保留文件名、大小、哈希与上传 ID，不保存文件本体。校验需额外读取一次源文件，大文件开始上传前可能需要等待。

只有源文件与接收端 SHA-256 一致才显示「已校验完成」；旧版客户端创建且没有源哈希的文件仍可下载，但显示「未核对源文件」。校验不替代 TLS，也不等于恶意软件扫描。

手机浏览器需保持前台；后台传输与原生分享入口将在原生客户端阶段实现。Office/PDF 等格式可传输和下载，目前不内嵌执行或解析其内容。不会自动扫描文件中的恶意软件。

## 开发与验收

```sh
npm test
npm run check
```

21 项测试已通过 Linux 和 Windows CI，包括真实 HTTPS 证书信任/主机名校验、加密上传下载和会话退出；4 项 Chromium 真实浏览器测试通过，覆盖桌面/手机视口上传、预览、下载及中断续传。本机 HTTP 超过 5 GiB 传输、服务重建续传与下载哈希验证已通过；这不等于 Android/iOS 真机或跨设备 Wi-Fi 验收。独立 Linux 临时文件系统实际写满后的断点保留、失败回滚与哈希一致续传也已通过。证据与复现命令见 [VALIDATION.md](docs/VALIDATION.md)，完整路线见 [ROADMAP.md](docs/ROADMAP.md)，协议见 [PROTOCOL.md](docs/PROTOCOL.md)。
